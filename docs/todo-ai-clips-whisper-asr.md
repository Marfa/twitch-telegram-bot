# TODO: Whisper ASR + visual cues for AI clips

Дата: 2026-10-05  
Статус: идея на будущее, реализация не начата

---

## Зачем

Сейчас AI-клипы берут моменты из:

1. текста чата VOD (`clip` / `клип`);
2. всплеска числа сообщений;
3. пиков громкости audio-only.

Два следующих тира (после чата + аудио):

| Тир | Что даёт |
|---|---|
| **A. Whisper / ASR** | Слышимое «клип» / «clip» (стример или зрители в войсе), даже без текста в чате |
| **B. Визуальные подсказки** | Текст/алерты на кадре (OCR) или «интересный момент» по кадрам (multimodal) |

---

## A. Whisper ASR (spoken «клип» / «clip»)

### Статус (2026-10-06)

Включено через Groq (`GROQ_API_KEY`): топ-10 audio → Whisper + emotion LLM
(балл >3 → кандидат); всплески чата → game/chat LLM. Приоритет клипов:
phrase → emotion → game → remaining audio → remaining spike. Без ключа /
429 — Groq-тиры пропускаются.

### Блокеры (локальный Whisper)

1. **VPS CPU/RAM** — текущий бот ~2 vCPU / ~1.8 GiB, контейнер bot 768 MiB. Полный Whisper на часовом VOD не влезает рядом с poll/Helix/dumps.
2. **Время** — ASR длинного VOD дольше, чем RMS + GQL chat; нужен отдельный durable job / очередь / лимит длины.
3. **Хранение** — audio для ASR нельзя держать долго (уже политика: temp delete после работы).

### Возможный путь позже

- Лёгкая модель (`tiny` / `base`) на отдельном worker, или оставить Groq.
- Только окна вокруг уже найденных chat/audio кандидатов *(уже так для Groq)*.
- Или отдельный worker-хост, не основной VPS бота.

## B. Визуальные подсказки на видео

### Варианты

1. **OCR по кадрам** (предпочтительный первый шаг) — сэмпл кадров VOD (например 1 кадр / 1–2 с вокруг кандидатов или редкий full-scan); PaddleOCR / EasyOCR; тот же regexp `(?i)clip|клип` по распознанному тексту (чат-оверлей, алерты на экране). Дешевле и предсказуемее «общего AI».
2. **Облачный multimodal LLM** (GPT-4o / Gemini Flash / Claude vision) — периодические кадры + вопрос «есть ли момент для клипа / реакция / мем». Практика для бота без своего GPU.
3. **Локальные video/action модели** (CLIP/SigLIP + классификатор, InternVideo, Video-LLaVA и т.п.) — на текущем VPS не sap; нужен отдельный GPU-worker.

### Блокеры

1. **VPS** — decode кадров + OCR/LLM рядом с ботом не влезает; нужен API или отдельный worker.
2. **Стоимость / квоты** — облачный vision на длинном VOD дорого; ограничивать окнами вокруг chat/audio кандидатов.
3. **Хранение** — кадры только во временном каталоге, удалять после job (как audio).

### Приоритет в пайплайне (когда появится)

После чата-текста и msg-spike, до или рядом с Whisper; audio RMS остаётся fallback. Точный порядок зафиксировать при реализации.
