1. First launch

  1. Open the bot and tap Start or send /start.
  2. Pick a language: English or Russian (you can change it later in Settings).
  3. You get a welcome message and the main menu buttons.

On first launch the bot may create a demo alert for a random Premium channel so you can see how notifications look. You can open or delete it with the buttons under that message.

If you send a Twitch channel link in DM while no wizard is open, the bot offers to create an alert for that channel.

3. New subscription

Tap ➕ New subscription. First choose an alert type:

TypeWhen you get a message
Stream startChannel goes live (everyone)
Category changeStreamer switches game/category ⭐ Premium
Upcoming streamReminder N minutes before official Twitch schedule ⭐
Stream endStream went offline ⭐

Wizard steps (short)

  1. Channel — login or twitch.tv / m.twitch.tv link. If you already have an alert for that channel, you can edit it or create another.
  2. Message — template with placeholders like {username}, {game}, {name}. Full list: placeholders.
  3. Extras — tick what you need: image, clean title (strips @streamers and !commands), ignore words ⭐, delayed send ⭐, repeat mute ⭐, delete previous messages ⭐, chat button, link preview.
  4. The bot then asks only for the steps you ticked.
  5. Destination — DM or channel/group. For a channel/group, add the bot and confirm the chat.

Every step has « Back, Cancel, and a way back to the menu. At the end you get “Setup complete” and a test message in the chosen chat.

Free plan: at most 5 active alerts. A 6th is created paused — enable after upgrade or pause another. marfapr and paid streamer Premium channels do not count toward that cap.

4. Import from Twitch

⬇️ Import subscriptions → Twitch OAuth → pick a mode:

  • One-time import — add follows now; token is not stored.
  • Sync ⭐ — every N days add new follows and remove unfollowed imports. Manual/edited alerts are left alone unless you confirm. Period is managed in Settings.

5. My subscriptions

📋 My subscriptions — paginated list. Per subscription:

  • enable / disable;
  • edit (channel, text, options, destination);
  • delete;
  • share an alert link (when available in beta mode).

Lower menu: cart (restore deleted: 10 days free, 30 Premium) and pause all alerts.

6. Alert history

📜 Alert history — what the bot already sent. Kept 7 days free, 60 with Premium. You can mark items as viewed.

7. Other

💬 Whisper alerts

Notify you about incoming Twitch whispers. First enable requires Twitch OAuth.

📅 Stream schedule

Build a weekly schedule or fix slots for one day, set timezone. Publishing slots to the Twitch schedule page is ⭐ Premium.

🎲 What to watch?

Random live streams by your filters (categories, tags, viewers, language, mature). If nothing is live — recent VODs. Save a filter and catch new streams matching it. Includes a “Feeling lucky” mode.

💬 Chat

Mini App to read and send Twitch stream chat. Free: read + up to 20 messages/day; unlimited with Premium.

8. Settings & Premium

⚙️ Settings typically includes:

  • ⭐ Premium — 7-day trial (once), Stars plans (month / year / lifetime), à la carte features, Twitch sub check on the developer channel, Premium channel for streamers.
  • Sync — follow auto-sync period or turn off.
  • System notifications — bot updates, availability, other broadcasts; Twitch status.
  • Language, advanced mode, beta mode (early access).
  • Partner program — referral link and a cut of invitees’ Stars Premium.
  • Ignored words — global list for alerts.

After a successful Stars payment the bot says: “Premium activated. Thank you!” and below that — how to contact @immarfa with your user ID if something goes wrong.

10. Free-plan limits

  • Up to 5 active alerts (more can stay paused).
  • Alert types other than stream start — Premium.
  • Advanced options (ignore, delay, repeats, delete previous) — Premium.
  • History 7 days, cart 10 days, chat with a daily send cap.
